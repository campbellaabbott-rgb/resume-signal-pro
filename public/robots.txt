# Search engines.
# Private / transactional routes are deliberately absent from sitemap.xml AND
# disallowed here: /auth, the per-user /account dashboard, the post-checkout
# pages (/success, /product-success, /payment-failed), the owner-only dashboards
# (/analytics, /errors, /health-check, /scan-metrics), the Agent Pass receipt
# (/agents/pass — signed-in only, reads the buyer's own row) and the OAuth
# consent route (/oauth/consent — exists only for an agent host's authorization
# request) have zero search value and must never be indexed. (Lovable's
# route-vs-sitemap checker flags these as "missing" — that is expected; do NOT
# add them to the sitemap.)
# Disallow is repeated per named group on purpose: a crawler obeys only its own
# most-specific User-agent block and never inherits rules from "*". The list is
# the PRIVATE_ROUTES allowlist in src/test/sitemap-prerender-parity.test.ts,
# and src/test/the-board-hands-a-job-and-a-search-to-the-agent.test.tsx fails
# when any of those routes is missing from any block here.
